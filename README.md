# Portfolio personal — Naia Cielo Funes

Versión final del portfolio personal de Naia Cielo Funes, estudiante del Instituto San Agustín e interesada en la informática.

## Secciones
- **Presentación:** nombre, formación e interés por la informática.
- **Sobre mí:** intereses personales y objetivos escolares.
- **Proyectos:** portfolio personal, sistema Convivia y página temática de Rapunzel.
- **Habilidades:** Python, HTML, CSS, organización de información y trabajo en equipo.
- **Contacto:** informa que por ahora no hay un correo o perfil profesional publicado.

## Proyectos
- **Convivia:** sistema para administrar información, desarrollado con Python en grupo.
- **Página de Rapunzel:** página web con imágenes y datos, realizada en grupo.
- **Portfolio personal:** sitio para presentar información personal y trabajos escolares.

## Estructura
- `index.html`: contenido y estructura semántica.
- `css/estilos.css`: colores, tipografías, distribución y diseño adaptable.
- `js/script.js`: menú desplegable para pantallas pequeñas.
- `bitacora_ia.md`: registro de consultas y decisiones de uso de IA.

## Cómo verlo
Abrí `index.html` con un navegador. No necesita instalar programas ni dependencias.

## Mejoras aplicadas
1. **Funcionamiento y navegación:** se agregó un menú desplegable para pantallas pequeñas, que se cierra al seleccionar una sección. También se incorporaron estados accesibles y estilos de foco para navegar con teclado.
2. **Contenido y diseño:** se reemplazaron las propuestas por los tres proyectos indicados, se completaron las secciones con los datos compartidos y se quitaron datos no confirmados.

## Publicación
El sitio puede publicarse en un servicio de alojamiento estático. La publicación en GitHub Pages requiere crear una cuenta y un repositorio desde la cuenta de la autora; actualmente no se incluye un perfil de GitHub porque Naia indicó que no tiene uno.
